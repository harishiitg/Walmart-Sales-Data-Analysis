# Walmart Sales Data Analysis

## Overview

This project analyzes Walmart sales data using SQL and Power BI to identify sales patterns, product performance, customer behavior, and revenue trends.

## Project Workflow

- Data Cleaning using SQL
- Data Analysis using SQL queries
- Exploratory analysis of sales patterns
- Dashboard creation using Power BI
- Identification of key business insights

## Key Analysis Areas

- Sales trends
- Product line performance
- Payment methods
- Customer gender analysis
- Revenue analysis
- Gross income analysis
- Sales by time

## Tools Used

- SQL
- Power BI

## Dashboard

The Power BI dashboard provides an interactive view of sales performance using KPIs, charts, filters, and product-level analysis.

## Key Insights

The analysis helps understand sales patterns across different product categories, payment methods, customer segments, and time periods.
